# Órbita 1.0.0

Papel de parede musical para Zorin OS 18 / GNOME Shell 46, exclusivamente na segunda área de trabalho e no monitor principal.

Terra e Lua com profundidade e movimento suave; letras sincronizadas; visualizador rítmico; vinil com capa do álbum e controles de reprodução.

Para instalar, baixe o .deb, instale pelo gerenciador de pacotes e abra **Órbita — Configurar**. Ative o visual e entre novamente na sessão do Zorin.

A integração opcional com o Spotify requer o cliente .deb x86_64. Spotify e Spicetify não estão incluídos nos arquivos da versão; a conexão baixa e verifica o Spicetify durante a preparação.

Consulte o README para compatibilidade, instalação portátil, licenças e remoção.
